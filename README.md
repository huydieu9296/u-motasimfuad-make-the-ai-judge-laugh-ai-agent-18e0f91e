# Make the AI Judge Laugh: AI Agent Secret Confession

Entry for the [make.fun bounty "Make the AI Judge Laugh: AI Agent Secret Confession"](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e).

The task: write one funny single-line secret confession an AI agent hides
from its user, under 200 characters.

## Run

Requires Node 22.18+ (the grader runs Node 22.23.4).

```sh
node main.ts
```

`main.ts` writes the confession (147 characters, one line) to
`/output/entry.txt`, validating first that it is non-blank, a single line,
and within the 200-character limit.
